# Visual Identity

## Visual philosophy
Carousels should be infographic-led and visual-design-led, not text-heavy.

## Every carousel needs a central visual object
Examples:
- Framework
- Map
- Scorecard
- Decision tree
- Evidence bank
- Operating system diagram
- Teardown
- Control panel

## Design direction
- Clear hierarchy
- Minimal text
- Strong diagrams
- High contrast
- Boardroom-ready visuals
- Useful enough to save and revisit
