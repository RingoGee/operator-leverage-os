# Free Vs Paid Logic

## Purpose of this file
Use this file to keep the boundary clear between what the audience learns for free and what they buy to implement faster.

This file follows `02-editorial-system/thought-leadership-doctrine.md`: free content must be intellectually strong enough to build trust, while paid content helps people apply the thinking faster.

## Core rule
Free content teaches argument, diagnosis, first-principles thinking, evidence-backed credibility, antithesis, frameworks, visual reasoning, and behavior shifts.

Paid content provides implementation assets.

Do not weaken free content just to push paid products. Paid products should not contain the “real thinking” while free content stays shallow.

## Free content creates trust and clarity
Free content should help people understand the problem, see why it exists, recognize the false solution, compare weak and strong operator behavior, and learn a reusable way to think or communicate better.

Free content includes:

- Arguments
- Diagnosis
- First-principles thinking
- Evidence-backed credibility
- Antithesis
- Mental models
- Frameworks
- Visual reasoning
- Teardowns
- Decision principles
- Operator thinking
- Communication models
- Small applied examples
- Behavior shifts

Free content should be complete enough that the reader can think better immediately.

## Paid content creates implementation speed
Paid content should help people apply the model faster with editable assets and operating systems.

Paid content includes:

- Templates
- Systems
- Canvases
- Trackers
- SOPs
- Prompt systems attached to workflows
- Operating kits
- Implementation kits
- Review checklists
- Sellable product packs

Paid content should not be secret knowledge. It should package execution, structure, and speed.

## Tools are not the free-content hook
ChatGPT, Codex, Notion, Sheets, n8n, Razorpay, or any other tool can appear only as an implementation layer. They should not lead the free idea.

A tool can help implement the system, but the system is the hero.

## Decision table
| If the idea is mainly... | Then it should be... | Reason |
| --- | --- | --- |
| A strong argument about why a work problem exists | Free | It builds authority and makes the brand worth following. |
| A first-principles diagnosis of messy work | Free | It helps the audience see the root cause, not just the symptom. |
| Evidence, example, or research that supports an operator insight | Free | It builds trust without requiring a purchase. |
| A reusable way to think, decide, diagnose, or communicate | Free | It teaches the operating model. |
| A visual explanation of a messy work problem | Free | It makes the brand save-worthy and thought-leadership-led. |
| A teardown that shows why something fails and how to fix the thinking | Free | It teaches judgment without requiring a template. |
| A behavior shift or operating question | Free | It changes how the reader approaches work. |
| An editable template, tracker, SOP, canvas, or operating kit | Paid | It helps the reader implement faster. |
| A prompt system connected to a specific framework or workflow | Paid | It is useful only when attached to the operating model. |
| A complete implementation system with examples and review steps | Paid | It reduces setup time and execution friction. |
| A list of prompts with no mental model | Reject | It becomes a generic prompt pack. |
| A tool tutorial with no thinking model | Reject | It makes the tool the hero instead of the system. |
| A promise of income, speed, or outcomes without proof | Reject | It attracts shortcut-seekers and weakens trust. |

## Paid-product guardrail
Paid assets should package implementation, not secret knowledge. The reader should understand the model for free and pay when they want a faster path to execution.

A healthy boundary looks like this:

- **Free:** “Here is why your work disappears and how strong operators make it verifiable.”
- **Paid:** “Here is the editable proof system, tracker, review rhythm, examples, and prompts to apply that thinking every week.”

If the free content feels shallow without the paid product, the system is wrong.
