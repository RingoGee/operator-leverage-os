# Carousel Quality Checklist

Before publishing, check:

- [ ] The post is mental model-led, not tool-led.
- [ ] The audience problem is specific.
- [ ] The hidden thinking flaw is clear.
- [ ] The mental model is reusable.
- [ ] There is one central visual object.
- [ ] The slides are not text-heavy.
- [ ] The post feels practical, sharp, and anti-hustle.
- [ ] The CTA matches the reader's stage.
- [ ] Any paid asset bridge is clearly separated from the free teaching.
