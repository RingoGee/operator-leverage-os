# OLS Design Prompt Builder

## Purpose
Convert an approved production draft into a design prompt direction file for Operator Leverage OS visual creation.

## When to use
Use after a production draft is approved and the user wants design-ready visual direction.

## Inputs required
- Approved production draft
- Optional visual style notes
- Optional prior generation feedback

## Source files to read
- Selected production draft in `07-exports/carousel-production-drafts/`
- `01-brand-foundation/visual-identity.md`
- `02-editorial-system/visual-carousel-rules.md`
- `03-carousel-system/visual-object-bank.md`
- `03-carousel-system/carousel-quality-checklist.md`

## Output files to create or update
- `07-exports/design-prompts/[number-topic-slug-design-prompts].md`

Design prompt file must include:

- Overall visual direction
- Premium analytical identity
- Locked slide chrome system
- Visual identity direction
- Signature accent palette
- Typography direction
- Mobile readability rules
- Slide-by-slide visual directions
- Composition archetype per slide
- Dominant element per slide
- Headline mode per slide
- Signature visual grammar per slide
- Evidence slide direction
- Antithesis slide direction
- Framework slide direction
- Application slide direction
- Final profile-entry slide direction
- What to avoid
- Design QA checklist

## Step-by-step procedure
1. Read production draft and visual system rules.
2. Convert slide production notes into design instructions.
3. Add locked chrome and brand grammar.
4. Add mobile-first layout guidance.
5. Specify where visuals should dominate over headlines.
6. Assign signature visual devices meaningfully.
7. Add avoid rules.
8. Save Markdown design prompt.

## Guardrails
- Do not create images.
- Do not create Canva files.
- Do not create visual execution pack unless asked.
- Do not invent brand visuals outside the approved visual identity.
- Do not make visuals decorative.
- Do not use generic SaaS/MBA/AI-tool aesthetics.
- Do not create final designed slides.

## Done when
- Design prompt file is complete.
- It is ready for visual execution pack creation.
- It preserves argument, hierarchy, and visual discipline.

## Summary format
1. File created
2. Design system choices
3. Slide-level visual logic
4. Chrome/signature grammar notes
5. Readiness for visual execution pack
6. Confirmation of no out-of-scope work
