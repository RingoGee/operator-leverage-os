## Where to find final carousel outputs

For final usable carousel handoff files, open only these two folders:

1. `07-exports/visual-generation-prompts/` — final copyable master prompt for ChatGPT Images or another image generation tool.
2. `07-exports/post-copy/` — final caption, hashtags, alt text, CTA, source note, and posting notes.

Upstream folders such as briefs, production drafts, design prompts, and visual execution packs can still exist for traceability, but they are not the final copy-paste handoff.

This root README is only an entry point. The main guidance lives inside `00-start-here/`.
