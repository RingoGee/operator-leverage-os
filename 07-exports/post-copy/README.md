# Post Copy Final Outputs

## Purpose
This folder contains the final posting text assets for each carousel.

If a carousel is ready to publish, this is the only folder the user should open for caption, hashtags, alt text, CTA, and posting notes.

## Required files per carousel
For each final carousel, create or expect two files:

1. `##_topic-slug-post-copy.md`
2. `##_topic-slug-post-copy.csv`

Example:

```text
13_ai-productivity-is-a-work-design-problem-post-copy.md
13_ai-productivity-is-a-work-design-problem-post-copy.csv
```

## Markdown file contents
Each `##_topic-slug-post-copy.md` file should contain:

- Carousel title
- Carousel ID / number
- Primary caption
- Short caption alternative
- Caption hook options
- CTA
- Hashtags
- Alt text / accessibility description
- Suggested first comment, if useful
- Posting notes
- Caveats / source note, if relevant

## CSV file columns
Each `##_topic-slug-post-copy.csv` file should use these columns:

```csv
carousel_id,title,caption,short_caption,caption_hook_options,cta,hashtags,alt_text,source_note,posting_notes
```

## Guardrails
- Keep post copy here, not inside upstream planning folders.
- Do not make the user open carousel briefs, production drafts, design prompts, or visual execution packs for publishing text.
- Do not store generated images, designed slides, Canva files, dashboards, apps, automations, products, or payment files here.
- Keep source notes honest and caveated when research or market evidence is used.
