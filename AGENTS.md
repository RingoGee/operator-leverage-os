# AGENTS.md

Guidance for future Codex tasks in this repository.

## Founder context
- Treat the repository owner as a non-technical founder/operator.
- Explain all changes in plain English.
- Prefer simple operating-system language over technical jargon.

## Build constraints
- Do not build an app unless explicitly asked.
- Do not write code unless explicitly asked.
- Prefer Markdown and CSV files.
- This repository is a content and product operating system, not a software application.

## Brand and editorial rules
- Keep free content mental model-led, not tool-led.
- Keep carousels infographic-led and visual-design-led, not text-heavy.
- Avoid generic AI tool lists, prompt dumps, income claims, and “make money with AI” content.
- Always separate free mental models from paid implementation assets.
- Tools such as ChatGPT, Codex, Notion, Sheets, n8n, and Razorpay are implementation layers, not the main content hook.

## Carousel brief requirements
Every carousel brief must define:
1. Audience problem
2. Hidden thinking flaw
3. Mental model
4. Central visual object
5. Slide-by-slide visual sequence
6. Minimal slide text
7. Paid asset bridge, if relevant

## Content philosophy
- Free content should teach people how to think, structure, communicate, and operate better.
- Paid content should help people implement with templates, systems, SOPs, canvases, and productized assets.
- Favor leverage over grind, clarity over complexity, and operator thinking over tool obsession.
