# Design Prompt Directions: Work-to-Impact Chain

## Direction note
This is a design direction document for the Work-to-Impact Chain carousel only. It is not final artwork, not designed slides, not an image file, and not a Canva file.

## 1. Overall visual direction
- Infographic-led and system-diagram-first.
- Operator-grade, calm, sharp, and high-signal.
- Low text with strong hierarchy.
- The carousel should feel like an operating diagram for ambitious professionals, not a social media listicle.
- No generic AI imagery.
- No corporate stock-photo feel.
- No hustle, grind, or motivational poster imagery.
- Use a restrained, structured design language: nodes, arrows, cards, labels, panels, and chain links.

## 2. Carousel format assumptions
- Format: Instagram carousel.
- Slide count: 7 slides.
- Composition: mobile-first square or portrait-friendly layout.
- Core system: one consistent visual object across all slides.
- Visual continuity: the same chain should appear, break, build, expand, or compress across slides.
- Text load: each slide should be understandable through labels and layout, not paragraphs.

## 3. Central visual object rules
The central object is a horizontal Work-to-Impact Chain:

**Work done → Output → Outcome → Proof → Leverage**

### Rules
- The chain can evolve slide by slide.
- The chain can begin broken, become complete, then be applied to an example.
- The chain should not be replaced by unrelated visuals.
- Avoid switching to random illustrations, stock-photo scenes, or decorative icon grids.
- The chain should feel like a reusable operating system, not a decorative timeline.

## 4. Slide-by-slide design prompt directions

### Slide 1: Problem frame
- **Slide purpose:** Show that useful work is easy to miss when it remains scattered.
- **Minimal visible text:** Useful work is easy to miss.
- **Visual composition:** Place a central operator/work node surrounded by scattered task cards: tasks, reports, follow-ups, meetings, fixes.
- **Visual hierarchy:** Main line at top or center; scattered work fragments below or around it.
- **Diagram elements:** Loose cards, disconnected dots, faint lines that do not connect into a chain yet.
- **Suggested visual metaphor:** Useful work as loose pieces without a signal path.
- **What to avoid:** Motivational pose, cluttered productivity board, laptop stock photo, dramatic burnout imagery.

### Slide 2: Hidden thinking flaw
- **Slide purpose:** Reveal that completed work does not explain its own impact.
- **Minimal visible text:** Work does not explain its own impact.
- **Visual composition:** Show a broken connection between “work done” and “impact understood.”
- **Visual hierarchy:** Make the broken link the focal point.
- **Diagram elements:** Two nodes separated by a gap; small label for missing proof layer.
- **Suggested visual metaphor:** Broken chain segment.
- **What to avoid:** Blaming the operator, self-promotion framing, exaggerated failure visuals.

### Slide 3: Mental model introduction
- **Slide purpose:** Introduce the Work-to-Impact Chain as the operating model.
- **Minimal visible text:** Turn work into proof through a chain.
- **Visual composition:** Reveal the full chain as a clean horizontal pipeline.
- **Visual hierarchy:** The chain should dominate the slide; text should support it.
- **Diagram elements:** Five linked nodes: Work done, Output, Outcome, Proof, Leverage.
- **Suggested visual metaphor:** Clean signal path from work to leverage.
- **What to avoid:** Long definitions, multi-row frameworks, unrelated icons.

### Slide 4: Full chain explanation
- **Slide purpose:** Explain the stages with compressed labels.
- **Minimal visible text:** Did → Shipped → Changed → Proved → Unlocked.
- **Visual composition:** Use the same chain, now with compressed labels above or inside each node.
- **Visual hierarchy:** Labels should be large enough to scan quickly; supporting prompts should stay tiny or off-slide.
- **Diagram elements:** Five nodes, arrows, subtle stage numbers, optional tiny captions only if space allows.
- **Suggested visual metaphor:** A translation layer that turns activity into leverage.
- **What to avoid:** Five long questions on the slide, dense worksheet layout, small unreadable text.

### Slide 5: Applied example
- **Slide purpose:** Run one concrete stakeholder/update example through the chain.
- **Minimal visible text:** Example: lead handover → cleaner follow-up.
- **Visual composition:** Show the same chain populated with the lead handover example.
- **Visual hierarchy:** Keep the chain as the hero; use short labels for each example stage.
- **Diagram elements:** Did: cleaned lead handover; Shipped: tracker; Changed: fewer stale leads; Proved: one weekly review; Unlocked: trust + evidence.
- **Suggested visual metaphor:** A messy handover becoming a clear proof trail.
- **What to avoid:** Full case study text, CRM screenshots, sales-dashboard visuals, excessive metric detail.

### Slide 6: Behavior shift
- **Slide purpose:** Clarify that visibility is the benefit and proof is the system.
- **Minimal visible text:** Visibility is the benefit. Proof is the system.
- **Visual composition:** Split screen: left side shows an activity list; right side shows the Work-to-Impact Chain.
- **Visual hierarchy:** Right side should feel calmer, clearer, and more structured.
- **Diagram elements:** Left: unchecked or flat activity items. Right: connected chain with proof node highlighted.
- **Suggested visual metaphor:** Scattered activity transformed into structured proof.
- **What to avoid:** Bragging imagery, personal branding visuals, loud promotional graphics.

### Slide 7: Save / apply
- **Slide purpose:** Make the carousel application-led and save-worthy.
- **Minimal visible text:** Use the chain before your next update.
- **Visual composition:** Compact reusable version of the chain, almost like a small operating card.
- **Visual hierarchy:** Application instruction first; chain second; optional sidebar note last.
- **Diagram elements:** Compact chain template with empty placeholders.
- **Suggested visual metaphor:** Pocket operating tool for work updates.
- **What to avoid:** Hard product pitch, Proof Stack as the main CTA, sales visual, urgency language.

## 5. Visual language

### Suggested layout grammar
- Use a consistent grid.
- Keep generous whitespace.
- Use cards or nodes for each chain stage.
- Use arrows to show movement from work to leverage.
- Use subtle section labels and clear hierarchy.
- Treat each slide like a system diagram.

### Typography direction
- Sharp, clean, modern sans-serif.
- Strong title weight, minimal body text.
- Stage labels should be bold and highly legible.
- Avoid handwritten, playful, or overly decorative type.

### Icon / diagram style
- Simple line icons only if they clarify the node.
- Prefer abstract diagram elements over literal illustrations.
- Icons should never replace the chain logic.
- Avoid random decorative icons.

### Use of arrows, labels, nodes, cards, panels, and chain links
- Use arrows for progression.
- Use nodes for each chain stage.
- Use cards for scattered work fragments on Slide 1.
- Use a broken chain link on Slide 2.
- Use a compact panel/card on Slide 7.
- Highlight “Proof” subtly on Slides 5 and 6.

### Suggested mood
Calm, useful, boardroom-ready, high-signal, structured, practical, and slightly contrarian.

## 6. Manual designer notes
- The fixed idea is the Work-to-Impact Chain.
- The fixed sequence is 7 slides.
- The fixed chain is: Work done → Output → Outcome → Proof → Leverage.
- The compressed stage labels are: Did → Shipped → Changed → Proved → Unlocked.
- The applied example should stay about lead handover and cleaner follow-up unless manually changed before design.
- The layout can be horizontal or portrait-adapted, but the chain must stay visually consistent.
- Proof Stack may appear only as a small optional future-facing note, not as the main CTA or sales visual.
- The designer can choose colors, spacing, and icon treatment, but should preserve the operator-grade system feel.
