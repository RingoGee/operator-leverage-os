# Free Vs Paid Logic

## Purpose of this file
Use this file to keep the boundary clear between what the audience learns for free and what they buy to implement faster.

## Core rule
Free content teaches mental models. Paid content provides implementation assets.

## Free content creates clarity
Free content should help people understand the problem, see the hidden thinking flaw, and learn a reusable way to think or communicate better.

Free content includes:
- Mental models
- Diagnostics
- Visual frameworks
- Teardowns
- Decision principles
- Operator thinking
- Communication models
- Small applied examples

## Paid content creates implementation speed
Paid content should help people apply the model faster with editable assets and operating systems.

Paid content includes:
- Templates
- Operating systems
- Canvases
- SOPs
- Prompt systems attached to a clear model
- Trackers
- Implementation kits
- Review checklists
- sellable product packs

## Tools are not the free-content hook
ChatGPT, Codex, Notion, Sheets, n8n, Razorpay, or any other tool can appear only as an implementation layer. They should not lead the free idea.

## Decision table
| If the idea is mainly... | Then it should be... | Reason |
| --- | --- | --- |
| A reusable way to think, decide, diagnose, or communicate | Free | It builds trust and teaches the operating model. |
| A visual explanation of a messy work problem | Free | It makes the brand save-worthy and mental-model-led. |
| A teardown that shows why something fails and how to fix the thinking | Free | It teaches judgment without requiring a template. |
| An editable template, tracker, SOP, canvas, or operating kit | Paid | It helps the reader implement faster. |
| A prompt system connected to a specific framework or workflow | Paid | It is useful only when attached to the operating model. |
| A list of prompts with no mental model | Reject | It becomes a generic prompt pack. |
| A tool tutorial with no thinking model | Reject | It makes the tool the hero instead of the system. |
| A promise of income, speed, or outcomes without proof | Reject | It attracts shortcut-seekers and weakens trust. |

## Paid-product guardrail
Paid assets should package implementation, not secret knowledge. The reader should understand the model for free and pay when they want a faster path to execution.
