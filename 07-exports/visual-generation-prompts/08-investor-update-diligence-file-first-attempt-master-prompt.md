# Visual Generation Prompt: The Investor Update Is Becoming a Diligence File

## Purpose of file
Copy this prompt into an external image/design generation tool to create the first visual attempt for the `Investor Update Diligence File` carousel.

## Usage notes
- Generate visuals only outside Codex.
- Do not create designed slides inside this repository.
- Do not add fake statistics about follow-on funding or investor response rates.

## Full copyable master prompt
Create an 8-slide Instagram carousel for Operator Leverage OS titled “Your Investor Update Is Not an Email. It Is a Diligence File.” The carousel should look like a founder's office investor communication system: precise, structured, calm, and high-signal.

Visual style: warm document background, charcoal typography, deep blue or green trust accents, muted red for broken KPI drift. Use modular document cards, timeline spines, folder metaphors, and clean control-panel layouts. Use consistent locked slide chrome: top-left `Capital & Narrative`, top-right slide number, bottom-left `Operator Leverage OS`, bottom-right source/caveat marker where relevant.

Core story: Investor updates become more useful when they form a comparable decision record over time. The visual system should transform an email into a diligence folder, show trust gaps from inconsistent updates, ground the idea in current investor workflow shifts, then introduce the six-part Diligence Trail Update.

Slide sequence:
1. Transformation visual: Investor update email folding into structured diligence folder. Text: “Your investor update is not an email.” Subline: “It is diligence before diligence.”
2. Broken timeline: Three monthly update cards with mismatched metrics, missing context, changed definitions. Text: “Random updates create trust gaps.”
3. Evidence cards: Card 1: “PitchBook/Web Summit: investors use AI to summarize diligence materials and identify deals.” Card 2: “Findex: precision, structure, and consistent health metrics matter.” Caveat: “AI-assisted does not mean fully automated.” Main text: “Structured inputs matter more, not less.”
4. Antithesis: Pretty update vs trusted record. Left card: “wins, screenshots, changing metrics.” Right card: “stable metrics, context, risks, asks, next proof.” Main line: “Pretty update ≠ trusted record.”
5. Mechanism spine: Six monthly update cards connected by a continuity spine. Stable fields repeat across every card. Text: “Trust compounds through continuity.”
6. Framework: Hero control panel titled “The Diligence Trail Update.” Six modules in a clean 2x3 grid: Baseline, Movement, Meaning, Risk, Ask, Next proof.
7. Application: Before/after update rewrite. Before: “Revenue was up and we hired two people.” After: “Expansion revenue rose because existing accounts added use cases. Burn increased after two GTM hires. Next proof: pipeline coverage improves without lowering qualification quality.” Add tags: movement, meaning, risk, next proof. Tiny note: “Fictional example for structure.”
8. Behavior shift: Six update cards leading to a trust signal. Text: “Write for the six-update reader.” Support: “Would six updates in sequence make the business easier to trust?” Profile line: “Operator Leverage OS — systems for sharper investor and operator communication.”
