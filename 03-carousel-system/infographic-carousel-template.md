## Recommended 7-slide visual structure

### Slide 1: Problem frame
- **Visual role:** Show the messy situation or pressure.
- **Minimal text:** One sharp problem statement.

### Slide 2: Hidden flaw
- **Visual role:** Show what the audience is misreading, skipping, or overcomplicating.
- **Minimal text:** One sentence naming the flaw.

### Slide 3: Mental model
- **Visual role:** Introduce the model as a simple structure.
- **Minimal text:** Name the model and its purpose.

### Slide 4: Central visual object
- **Visual role:** Show the full map, tree, scorecard, panel, stack, or system.
- **Minimal text:** Labels only where possible.

### Slide 5: Applied example
- **Visual role:** Run one realistic operator situation through the model.
- **Minimal text:** Short labels showing before and after clarity.

### Slide 6: Decision or behavior shift
- **Visual role:** Show what changes in thinking, communication, or execution.
- **Minimal text:** One practical takeaway.

### Slide 7: Save / apply / bridge
- **Visual role:** Summarize the reusable structure or next action.
- **Minimal text:** Save, apply, or optional paid implementation bridge.
