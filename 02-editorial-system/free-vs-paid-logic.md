# Free Vs Paid Logic

## Free content teaches
- Mental models
- Visual frameworks
- Diagnostics
- Teardowns
- Decision principles
- Operator thinking
- Communication models

## Paid content provides
- Templates
- Notion or Sheets systems
- Prompt systems
- Operating system kits
- Editable canvases
- SOPs
- Implementation guides
- sellable product packs

## Rule
Free content should create clarity. Paid products should create implementation speed.
