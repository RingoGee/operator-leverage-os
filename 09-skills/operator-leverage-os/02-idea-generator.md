# OLS Idea Generator

## Purpose
Convert research findings, operator problems, audience pain points, or strategic themes into structured Operator Leverage OS topic ideas.

## When to use
Use after a research scan or when the user asks for content ideas, topic-bank additions, pillar-wise ideas, launch sequence ideas, or theme expansion.

## Inputs required
- Research findings, source notes, or theme
- Target pillar or audience segment
- Desired number of ideas
- Optional product bridge
- Optional content format preference

- pillar
- audience_segment
- topic_title
- operator_problem
- hidden_thinking_flaw
- first_principles_cause
- evidence_or_example_angle
- antithesis
- mental_model_or_framework

- potential_content_format

- paid_asset_bridge
- priority
- status

## Step-by-step procedure
1. Read source doctrine and topic bank.
2. Identify idea territories.
3. Avoid duplicating existing topics.
4. Generate topic candidates using Operator Leverage OS standards.
5. Separate weak ideas from strong ideas.
6. Classify each idea by pillar and audience segment.
7. Identify possible evidence/example layer.
8. Identify whether the idea deserves:
   - field note
   - antithesis map
   - decision tool
   - flagship visual memo
   - operator teardown
9. Recommend which ideas should become briefs.
10. Update topic-bank only if explicitly asked.

## Guardrails
- Do not create finished posts.
- Do not create carousel briefs unless asked.
- Do not create design prompts.
- Do not generate visuals.
- Do not create shallow listicles.
- Do not create generic AI-tool topics.
- Do not force a named framework.
- Do not duplicate existing topic-bank ideas.
- Do not weaken free content to force paid conversion.

## Done when
- Ideas are structured.
- Strongest ideas are prioritized.
- Weak/repetitive ideas are filtered.
- Recommended next actions are clear.

## Summary format
1. Number of ideas generated
2. Pillar distribution
3. Strongest ideas
4. Ideas rejected or deprioritized
5. Suggested next skill to run
