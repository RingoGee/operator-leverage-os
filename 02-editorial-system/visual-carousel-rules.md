# Visual Carousel Rules

## Carousel standard
Each carousel must be built around one central visual object.

## Slide rules
- One idea per slide.
- Minimal slide text.
- Use diagrams, grids, scorecards, maps, or control panels.
- Make the carousel save-worthy.
- Avoid turning slides into essays.

## Required carousel brief fields
1. Audience problem
2. Hidden thinking flaw
3. Mental model
4. Central visual object
5. Slide-by-slide visual sequence
6. Minimal slide text
7. Paid asset bridge, if relevant
