# OLS Carousel Auditor

## Purpose
Audit generated Operator Leverage OS carousel visuals against the repo doctrine, visual system, Instagram performance logic, and brand standards.

## When to use
Use after the user shares generated carousel images or visual output.

## Inputs required
- Carousel images or design output
- Relevant carousel files
- Optional user concerns

## Source files to read
- Relevant brief
- Relevant production draft
- Relevant design prompt
- Relevant visual execution pack
- Relevant visual generation prompt
- `02-editorial-system/thought-leadership-doctrine.md`
- `02-editorial-system/visual-carousel-rules.md`
- `03-carousel-system/carousel-quality-checklist.md`
- `03-carousel-system/visual-object-bank.md`

## Output files to create or update
Usually none.

If explicitly requested:

- `07-exports/carousel-audits/[number-topic-slug-audit].md`

Audit criteria:

- strategic argument
- slide-by-slide flow
- mobile readability
- slide chrome consistency
- memo/page numbering
- evidence honesty
- first-principles diagnosis
- antithesis strength
- mechanism clarity
- framework usefulness
- application usefulness
- behavior shift
- profile-entry reason
- composition archetype fit
- dominant element clarity
- headline hierarchy
- signature visual grammar
- brand ownability
- save/share/profile-entry potential
- publish readiness

## Step-by-step procedure
1. Inspect output slide by slide.
2. Compare against source files.
3. Identify what works.
4. Identify must-fix issues.
5. Identify nice-to-fix issues.
6. Decide whether to:
   - publish
   - manually polish
   - revise prompt and regenerate
   - revise doctrine/system
7. Provide readiness score.

## Guardrails
- Do not edit files unless explicitly asked.
- Do not generate images.
- Do not rewrite the carousel during audit unless asked.
- Do not be overly positive.
- Be critical and specific.
- Do not ignore mobile readability.

## Done when
- Audit is complete.
- Readiness score is provided.
- Next action is clear.

## Summary format
1. Overall verdict
2. Score
3. What works
4. Slide-by-slide audit
5. Must-fix issues
6. Nice-to-fix issues
7. Recommended next action

## Brand Identity Lock v1 audit checks
Audit every carousel for Brand Identity Lock v1 consistency:

- Palette follows the locked system.
- Typography follows the locked editorial pairing.
- Chrome placement is stable.
- Spacing and safe margins are consistent.
- Diagram/icon style is clean, restrained, and meaningful.
- Surface treatment is warm, subtle, and premium.
- Mobile readability is preserved.
- House style is recognizable.
- The carousel varies argument, slide structure, or visual object without becoming visually unrelated.

Final audit questions:

- Does this feel like the same publication as other Operator Leverage OS posts, while still having a distinct argument?
- Would a reader recognize the brand without every carousel using the same template?
- Is the balance right: same brand, different argument?

## Free Value Per Slide audit
Audit whether each slide gives useful standalone reader value.

For every slide, rate:

- useful takeaway;
- practical lens;
- action or judgment improvement;
- plain-language clarity;
- useful density without clutter.

Reject carousels that look good but feel thin.

Final audit questions:

- Would the reader feel they received a useful operating lens for free?
- If this slide were removed from the carousel, would the reader lose a specific useful idea?

## Minimum text readability audit
Audit every generated carousel for Instagram mobile reading.

Check:

- Is every meaningful text element readable on Instagram mobile?
- Is the smallest meaningful text comfortably readable on mobile?
- Does any essential idea depend on microcopy?
- Are diagram labels readable without zooming?
- Are body text and diagram labels visibly larger than source/chrome text?
- Are source notes, caveats, memo codes, and chrome non-essential?
- Are small labels supportive rather than essential?
- Would the slide still work when viewed quickly on Instagram?

Rate minimum text readability:

- **Pass:** all essential text and labels are readable without zoom.
- **Rework:** one or two support labels are slightly small but not essential.
- **Reject:** any essential idea depends on tiny text or unreadable diagram labels.

## Narrative continuity audit
Audit whether the carousel feels like one guided argument.

Check:

- Does every slide connect to the previous slide?
- Does every slide create a reason to move to the next?
- Is there a clear reader question chain?
- Does the evidence slide lead naturally to the contrast/mechanism slide?
- Does the framework slide feel earned?
- Does the application slide feel like the natural next step?
- Does the final slide resolve the argument?
- Can the reader follow the carousel without feeling reset at every slide?
- Does each slide make the next slide feel necessary?
- Does the carousel feel like one guided argument?

Rate slide transitions:

- **Seamless:** each slide answers the previous question and opens the next.
- **Somewhat abrupt:** most slides connect, but one transition feels like a reset.
- **Abrupt:** the deck feels like separate good cards rather than one argument.

Rate one-argument coherence:

- **Pass:** one coherent argument carries through the deck.
- **Rework:** argument is present but interrupted by loose slides.
- **Reject:** slides are individually strong but disconnected.
