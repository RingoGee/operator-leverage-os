# The Invisible Work Problem — Third-Attempt Master Visual Generation Prompt

## 1. Purpose of this file

This file contains the **third visual generation master prompt** for the **Invisible Work Problem** carousel.

It is meant to be copied into an image or design generation tool when attempting to generate the full 8-slide carousel in one go.

The goal is not to create a generic carousel. The goal is to generate a mobile-readable visual strategy memo: structured, high-signal, distinctive, analytical, and useful enough to save.

## 2. Usage notes

- Use the full master prompt below if generating all 8 slides at once.
- If the tool struggles with full-deck generation, use the slide-by-slide prompts from `07-exports/visual-execution-packs/01-the-invisible-work-problem-visual-execution-pack.md` instead.
- Prioritize mobile readability over decorative complexity.
- If any slide becomes crowded, simplify the layout while preserving the argument.
- Keep the output as a visual carousel only. Do not add paid-product language, fake statistics, dashboards, charts, links, automation references, or tool-led AI aesthetics.

## 3. Full copyable master prompt

```text
Generate an 8-slide Instagram carousel deck in portrait 4:5 format.

Carousel title:
The Invisible Work Problem

Brand:
Operator Leverage OS

Brand meaning:
A premium analytical thought-leadership brand about operator leverage: helping ambitious professionals, founders, consultants, and strategy operators turn messy work into clear systems, proof, decisions, and visible leverage.

Visual direction:
- Premium analytical memo
- Strategic field manual
- Visual operating manual
- Compressed strategy memo with diagrams
- Sleek, stylish, classy, grounded, practical
- Mobile-readable
- Structured visual reading
- Evidence-backed visual argument

Avoid:
- Generic SaaS carousel
- First-year MBA classroom slide
- Motivational productivity post
- AI tools account
- Corporate training deck
- Startup infographic template
- Stock corporate presentation
- Generic icons
- Robots
- Glowing AI brains
- Laptop stock imagery
- Decorative icons
- Fake statistics

Visual identity:
- Format: Instagram portrait 4:5
- Slides: 8
- Base background: warm off-white / ivory
- Primary text: deep navy-charcoal
- Signature accent: electric amber / proof-orange
- Secondary evidence accent: slate blue
- Leakage/loss accent: muted red
- Verified proof accent: deep green
- Grid/footer elements: quiet warm grey
- Typography: premium modern sans-serif with small monospace-style labels where useful
- Layout: structured, editorial, high-signal, mobile-readable
- Use thoughtful whitespace
- Use structured text, not paragraph blobs
- Use annotations, evidence cards, proof stamps, leakage points, decision gates, and “so what?” callouts where helpful

Global design rules:
- Every slide must have one dominant idea.
- Every slide must have a clear primary reading zone.
- Supporting text should be structured into labels, cards, tables, callouts, or annotations.
- Do not make text tiny.
- Do not repeat the same layout across all slides.
- Each slide must advance the argument.
- Visuals must reveal structure, contrast, causality, or decision logic.
- Visuals must not merely repeat the headline.
- Do not invent statistics.
- Do not include fake source citations.
- Do not mention Proof Stack or any paid product in the visual carousel.

Core thesis:
Useful work disappears when it is not converted into reusable proof.

Main argument:
The work that gets remembered is not always the work that mattered most. It is the work that became proof.

Framework:
The Proof Conversion Funnel:
Work done → Captured → Connected to outcome → Verified by signal → Stored as proof → Reused for leverage

Core mechanism:
Work loses value at every stage where it is not captured, connected, verified, stored, or reused.

Create the following exact 8-slide sequence.

SLIDE 1 — Tension / stopping power

Main text:
“The work that gets remembered is not always the work that mattered most.
It is the work that became proof.”

Visual move:
Contradiction split / memory gap.

Layout:
- Top primary zone: large headline text.
- Bottom secondary zone: split visual.
- Left side label: “Work that mattered”
- Right side label: “Work that got remembered”
- Middle gap label: “Proof gap”

Visual details:
Left side should show valuable but fading work artifacts: notes, decisions, fixes, conversations, handoffs.
Right side should show permanent proof artifacts: evidence card, proof stamp, decision note, review-ready signal.
Do not show the full Proof Conversion Funnel yet.

Annotation:
“Value is not enough if it cannot be recalled.”

Avoid:
Do not explain the entire framework on Slide 1.
Do not include too many tiny cards.
Do not make this look like a generic business comparison slide.

SLIDE 2 — First-principles diagnosis

Main text:
“Organizations do not remember effort reliably.”

Support text:
“They remember proof, decisions, outcomes, and evidence that can be reused.”

Visual move:
Root-cause map.

Layout:
- Primary zone: diagnosis headline.
- Secondary zone: four cause nodes.
- Footer/annotation zone: one “so what?” line.

Cause nodes:
1. Weak memory
2. Limited attention
3. Incomplete evidence trails
4. Decision moments need reusable proof

So what note:
“Work disappears when it lives only in memory, meetings, or scattered updates.”

Visual details:
Use a clean root-cause map or system map. Keep the four causes readable. Use slate blue for structural causes and proof-orange for the key proof idea.

Avoid:
Do not overload with arrows.
Do not add extra explanations beyond the four causes and one so-what note.

SLIDE 3 — Evidence / example

Main title:
“Mini-case: same work, different proof trail.”

Subtitle:
“Two operators contribute to the same project. One is easier to remember.”

Visual move:
Illustrative workplace mini-case.

Layout:
Two side-by-side cards.

Left card:
Label: “Memory-based”
Text:
“Waits until review season.
Says: ‘I worked on the launch.’”

Right card:
Label: “Proof-trail based”
Text:
“Captures weekly decisions, signals, comments, assets, and outcomes.”

Bottom insight:
“The difference is not only the work. It is the retrievable proof around the work.”

Small note:
“Illustrative workplace example”

Avoid:
Do not write “not a sourced statistic” as visible main copy.
Do not pretend this is research.
Do not use fake percentages.

SLIDE 4 — Antithesis / contrast

Main title:
“Invisible operators rely on memory.
High-leverage operators build evidence trails.”

Visual move:
Antithesis table.

Layout:
Two-column comparison table.

Left column:
“Default operator”

Rows:
- Relies on memory
- Reports activity
- Waits for review season
- Says “I worked on X”
- Depends on interpretation

Right column:
“High-leverage operator”

Rows:
- Builds evidence trails
- Connects work to outcomes
- Captures proof weekly
- Shows before/after change
- Reuses proof in decisions

Visual details:
Make this slide highly readable and shareable.
Use muted red or grey for default patterns.
Use proof-orange and deep green for high-leverage patterns.

Avoid:
Do not insult the default operator.
Do not make this feel like hustle/self-promotion advice.
Keep it analytical.

SLIDE 5 — Hidden mechanism

Main title:
“Work loses value at every proof break.”

Visual move:
Leakage map / conversion-break map.

Layout:
A vertical or diagonal staged path.

Stages:
1. Work done
2. Not captured → becomes memory
3. Not connected → becomes activity
4. Not verified → becomes a claim
5. Not stored → becomes scattered context
6. Not reused → loses leverage

Use short labels:
- Capture leak
- Outcome leak
- Signal leak
- Storage leak
- Reuse leak

So what note:
“Value does not vanish at once. It leaks at every proof conversion break.”

Visual details:
Use muted red for leak points.
Use proof-orange for the path that survives.
Keep labels large enough for mobile.

Avoid:
Do not make this a cluttered technical flowchart.
Do not add many tiny annotations.

SLIDE 6 — Framework / save-worthy model

Main title:
“The Proof Conversion Funnel”

Subtitle:
“How work becomes reusable proof.”

Visual move:
Framework model / conversion gates.

Primary stages:
Work done
→ Captured
→ Connected to outcome
→ Verified by signal
→ Stored as proof
→ Reused for leverage

Secondary support:
“Reused in weekly updates, stakeholder reviews, appraisal narratives, decision memos, handoffs, and case studies.”

So what note:
“Proof becomes useful when it can travel into decisions.”

Visual details:
Make this the most save-worthy slide.
Use a memo-style conversion ladder or gated funnel, not a generic marketing funnel.
Each stage should feel like a conversion gate.
Use proof-orange for gates and deep green for verified proof.
Keep the six stage questions out of the main visual.

Avoid:
Do not make this a worksheet.
Do not include too much small text.
Do not over-design the funnel.

SLIDE 7 — Application / weekly review artifact

Main title:
“Turn a weak update into reusable proof.”

Visual move:
Structured weekly review artifact.

Left side:
Weak update

Quote:
“Worked on reducing customer escalations this week.”

Right side:
Proof-converted update

Use structured fields, not a long quote:

Risk / problem:
Repeat escalation risk

Action taken:
Identified top 3 recurring handoff gaps

Ownership / alignment:
Aligned support + product on ownership

Signal / proof:
Closed 2 process gaps and captured before/after escalation signals

Reuse moment:
Next week’s stakeholder review

Bottom note:
“Proof conversion is information design.”

Visual details:
Make the right side look like a clean operator memo or weekly review card.
Use proof-orange labels and slate-blue structure.
Use deep green for signal/proof.

Avoid:
Do not put the full proof-converted update as one long paragraph.
Do not use generic email mockups.
Do not make it look like a template marketplace product.

SLIDE 8 — Behavior shift + profile reason

Main text:
“Before your next update, ask:
what proof did this work create?”

Visual move:
Behavior checklist + profile reason.

Checklist:
- Captured?
- Connected?
- Verified?
- Stored?
- Reusable?

Profile-entry line:
“More operator leverage systems for people turning invisible work into visible proof.”

Layout:
- Primary zone: behavior question
- Secondary zone: five-point checklist
- Footer/profile zone: category promise
- Use proof-orange to highlight the key question
- Use quiet grid and field-manual styling

Avoid:
Do not make this a hard sales CTA.
Do not mention a product.
Do not use “DM me” or fake urgency.
Do not make the footer too small to read.

Final quality guardrails:
- Keep all text mobile-readable.
- Use structured density, not clutter.
- Avoid tiny labels.
- Avoid repeated slide layouts.
- Avoid generic icons.
- Avoid fake statistics.
- Avoid an over-muted, forgettable palette.
- The design should feel distinctive, premium, analytical, and useful.
- The carousel should reward both quick scanning and deeper reading.

Additional generation instruction:
Prioritize mobile readability over decorative complexity. If any slide becomes visually crowded, simplify the layout while preserving the argument.
```

- [ ] Slide 5 leakage map is readable.
- [ ] Slide 6 funnel is save-worthy, not cramped.
- [ ] Slide 7 is a structured artifact, not a long quote.
- [ ] Slide 8 profile reason is visible enough.
- [ ] Whole deck has a distinctive signature palette.
- [ ] Whole deck avoids boring consulting beige.
- [ ] Whole deck avoids repeated template monotony.
- [ ] Whole deck avoids fake data and generic icons.
