# The Invisible Work Problem — Final Next-Attempt Master Visual Generation Prompt

## 1. Purpose of this file

This file contains the final pre-generation master prompt for the next full visual attempt of the **Invisible Work Problem** carousel.

It is meant to be copied into an image or design generation tool when attempting to generate the full 8-slide carousel in one go.

The goal is to generate a mobile-readable visual strategy memo: structured, high-signal, distinctive, analytical, and useful enough to save. The deck must feel like an Operator Leverage OS field manual, not a generic carousel template.

## 2. Usage notes

- Use the full master prompt below if generating all 8 slides at once.
- If the tool struggles with full-deck generation, use the slide-by-slide prompts from `07-exports/visual-execution-packs/01-the-invisible-work-problem-visual-execution-pack.md` instead.
- Prioritize mobile readability over decorative complexity.
- If any slide becomes crowded, simplify the layout while preserving the argument.
- Keep the output as a visual carousel only. Do not add paid-product language, fake statistics, dashboards, charts, links, automation references, or tool-led AI aesthetics.
